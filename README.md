# 나의 포트폴리오 웹사이트

간단한 자기소개 포트폴리오 웹사이트입니다. 소개, 작업물, 연락처 세 페이지로 이루어져 있습니다. HTML과 CSS만으로 만들었고, Claude Code와 함께 만들어보며 웹 페이지 구조와 Git 사용법을 익히는 연습 프로젝트입니다.

## 폴더와 파일 구조

```
README 작성/
├── index.html    # 소개 페이지 (첫 화면)
├── works.html    # 작업물(만든 것들) 목록 페이지
├── contact.html  # 연락처 페이지
├── style.css     # 세 페이지가 함께 사용하는 스타일 파일
└── README.md     # 이 문서
```

## 실행 방법 (브라우저로 여는 법)

### 방법 1. 배포된 사이트 바로 보기

아래 주소로 접속하면 바로 확인할 수 있습니다.

👉 https://donghyeok-91.github.io/Homework-4Week/

### 방법 2. 내 컴퓨터에서 직접 열기

1. 이 폴더를 다운로드하거나 `git clone`으로 내려받습니다.
2. `index.html` 파일을 더블클릭하면 기본 브라우저에서 바로 열립니다.
3. 상단 메뉴(소개 / 작업물 / 연락처)를 눌러 다른 페이지로 이동할 수 있습니다.

> 별도의 설치나 서버 실행이 필요 없습니다. 브라우저만 있으면 됩니다.

## 배운 것

- HTML로 여러 페이지를 만들고 `<nav>` 메뉴로 서로 연결하는 방법을 배웠습니다.
- CSS 변수(`:root`)를 사용해 색상 같은 공통 값을 한 곳에서 관리하는 방법을 배웠습니다.
- `@media` 쿼리로 화면 크기에 따라 레이아웃이 바뀌는 반응형 디자인을 배웠습니다.
- Git으로 파일을 추적(add)하고 커밋(commit)한 뒤 GitHub 원격 저장소에 push하는 흐름을 배웠습니다.
